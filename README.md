# 📰 Dudung News

Portal berita modern yang dibangun dengan **Nuxt 3** (kompatibel Nuxt 4), mengambil data dari endpoint API `https://api.npoint.io/749e4cc46af7d03db38a`.

## ✨ Fitur

- 🔍 **Pencarian** artikel berdasarkan judul & deskripsi
- 👤 **Filter** berdasarkan penulis
- 🔃 **Urutan** terbaru atau terlama
- 🃏 **Tampilan Card** grid yang responsif
- 📋 **Tampilan List** terurut dengan detail
- 📖 **Modal detail** artikel
- 💅 Desain editorial *newspaper noir* yang unik

## 🚀 Cara Menjalankan

```bash
# Install dependencies
npm install

# Development
npm run dev

# Build untuk production
npm run build

# Generate static
npm run generate
```


## 🛠 Tech Stack

- Nuxt 4
- Google Fonts: Playfair Display + DM Sans
